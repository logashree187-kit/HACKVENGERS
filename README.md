# LostFound+

A smart Lost and Found Management Platform built for a MongoDB hackathon.

## Problem

Lost items are difficult to track, search and reconnect with their owners.

## Solution

LostFound+ allows users to:

- Report lost items
- Report found items
- Search and filter reports
- Find possible matching items
- Submit claims
- Track item status
- Manage claims through an admin dashboard
- View MongoDB-powered analytics

## Technology Stack

- React
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- REST API
